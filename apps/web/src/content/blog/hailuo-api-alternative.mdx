MiniMax Hailuo is not on Aigenway, and we're not going to pretend otherwise. If you're evaluating a Hailuo API alternative because you want prepaid USD billing, a second model to compare against, or one gateway instead of a separate credit balance per vendor, here's the honest comparison — and how Kling, Veo 3 and Seedance cover the same ground behind one API key.

## Why Hailuo isn't here, and what you're trading away

MiniMax runs Hailuo on its own hosted API with its own account, its own credit system, and its own model line — fast turnaround and strong character consistency across shots are the features Hailuo users lean on most. We don't proxy MiniMax, so if a project depends specifically on Hailuo's exact motion signature or a feature unique to that model line, nothing on this gateway reproduces it exactly, and we'd rather say so upfront than sell a workaround that quietly falls short. What you gain by switching is the part that isn't tied to a single vendor: one integration across three independently-trained video models instead of one, and billing you can read from an API instead of a credit-pack dashboard.

## What replaces it: Kling, Veo 3, Seedance

These three cover most of what Hailuo users actually reach for — image-to-video animation, native-audio generation, and fast, cheap iteration for drafts:

- **Kling** — fluid motion and strong image-to-video, plus Motion Control for transferring a reference video's motion onto a character.
- **Veo 3** — Google's flagship, with audio (dialogue, SFX, ambience) generated in the same pass as the picture.
- **Seedance** — ByteDance's model, fast render times and a low cost per second, a close match for Hailuo's speed-focused workflow.

Confirm the live model codes for whichever one you pick before hardcoding a string — availability and versions move:

```bash
curl "https://api.aigenway.com/v1/methods?provider=seedance" \
  -H "Authorization: Bearer sk_live_..."
```

## A concrete call: image-to-video

The core Hailuo use case — animate a starting frame with a motion prompt — maps directly onto the same request shape here:

```bash
curl -X POST https://api.aigenway.com/v1/generations \
  -H "Authorization: Bearer sk_live_..." \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "seedance",
    "model": "seedance-1-lite",
    "method": "image_to_video",
    "params": {
      "prompt": "subject turns to face the camera, neon signage flickers in the background",
      "input_image": "https://example.com/frame.png",
      "duration": 5
    }
  }'
```

`Idempotency-Key` makes retries safe — resend the same key on a dropped connection and you get back the same task instead of paying for a second render.

## The async task and webhook flow

Video generation is never synchronous on any provider, Hailuo included — the `POST` above returns a task in `queued` or `processing` state, not a finished clip. Two ways to get the result:

1. **Poll.** `GET /v1/generations/{task_id}` until `status` becomes `succeeded` (or `failed`), then read the output URL off the response.
2. **Webhook.** Set a `callback_url` on the request and the gateway `POST`s the finished task to your endpoint as soon as it's ready — no polling loop to write.

```bash
curl -X POST https://api.aigenway.com/v1/generations \
  -H "Authorization: Bearer sk_live_..." \
  -H "Idempotency-Key: $(uuidgen)" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "veo",
    "model": "veo-3",
    "method": "text_to_video",
    "params": { "prompt": "a street vendor calls out over the noise of a night market, steam rising off a wok", "duration": 8 },
    "callback_url": "https://your-app.example.com/webhooks/aigenway"
  }'
```

The task shape — fields, status values, webhook signature — is identical across Kling, Veo 3 and Seedance, so code written against one drives all three. Details in the [task lifecycle](/docs/task-lifecycle) docs.

## Why one gateway beats a Hailuo-only account

- **Three models, one integration.** Swap `provider`/`model` to compare Kling against Veo 3 or Seedance on the same brief instead of committing to one vendor's look.
- **Prepaid per-second USD.** One balance, no credit-pack tiers to forecast or top up per provider.
- **Production plumbing included.** Idempotency keys, a queue, task state and signed webhooks, already built.

If a Hailuo-specific feature is the actual requirement, keep a MiniMax account for that specific job. For everything else — prompt-driven and image-to-video generation — Kling, Veo 3 and Seedance behind one key cover it, and you can compare all three without rewriting your integration each time.
